# Triage labels

The five canonical triage roles. Label string equals role name.

| Role | Label |
|---|---|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

`wontfix` already existed as a GitHub stock label and is reused rather than duplicated.
